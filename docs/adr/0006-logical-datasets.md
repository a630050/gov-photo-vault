# 資料集是獨立於檔案目錄的業務集合

2026-11-23 確認：採「科室 → 項目 → 資料集 → 照片」四層，每張照片歸屬一個資料集並沿用項目的屬性表單。介面中的資料夾即資料集，不直接對應網路芳鄰實體目錄，避免業務重新命名造成原圖搬移。

具上傳權限者可於授權項目建立資料集，建立者可修改名稱與說明並留存紀錄。主管及系統管理者可封存或重新開放；封存後保留查詢，停止新增照片與一般整理操作，仍可申請更正或刪除。第一版不提供整個資料集跨項目搬移，含照片的資料集不可直接刪除。

封存保留草稿但暫停提交，已啟動分析可完成，不可新啟動分析；個人打星與既有異常案件審核可繼續，共享標籤與新增異常標註暫停。照片可申請移至同科室同項目的另一未封存資料集，主管或管理者核准；保留照片 ID、表單版本、標籤、打星及異常紀錄，記錄歸屬變更並標示舊分析範圍已變動。第一版不支援跨科室或跨項目移動。

同項目資料集名稱不得重複，含封存資料集；不同項目可同名。資料集另有不變編號，改名不改編號。已有照片或歷史紀錄的項目只能停用，不可直接刪除；停用停止建立資料集及新增提交，歷史照片仍可搜尋、比對及依權限處理，側欄預設隱藏但可選包含停用項目。停用標籤、表單版本及異常類型仍保留歷史名稱與解讀能力。
