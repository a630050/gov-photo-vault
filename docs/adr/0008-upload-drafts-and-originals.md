# 批次上傳先存草稿，保留原始照片

2026-11-23 確認：上傳前選定科室、項目及資料集，照片先進草稿，僅本人及管理者可見；支援共同欄位批填及逐張調整。可逐部分提交，失敗或未完成的照片留在草稿；拍攝時間或位置缺漏可提交並進待補清單，其他必填表單欄位須完整。草稿中的「管理者」可見範圍沿用既有科室角色邊界，非跨科室通用授權。

第一版支援 JPEG、PNG、WebP 與 HEIC 靜態圖片，完整保存原檔並生成瀏覽版本；不支援 RAW、影片或 Live Photo 動態部分，逐檔顯示不支援原因。同一資料集內檢查檔案完全一致的重複，預設略過，填理由可另建紀錄；不跨資料集提示，不自動執行近似分析。

照片有時區則依原始資訊換算，無時區預填臺灣時間並標明推定，允許批次確認；未確認者可瀏覽，不直接作為近似分析時間異常的判定依據。保留原始 EXIF 與確認後時間。定位支援地圖點選或輸入經緯度，保留原始與修正座標、理由及操作者；批次設定須明確勾選並確認張數，不自動用電腦位置替代。

上傳頁支援手機瀏覽器，地圖與雙圖比對以桌機優先。既有照片由管理者發起批次匯入，先預覽來源目錄與檔案，再指定科室、項目及資料集；不自動監看整個網路芳鄰，不搬走或刪除來源檔案。

既有照片匯入須複製到系統管理儲存區並驗證成功，來源檔保持不動。匯入先進草稿，由管理者補齊後批次提交，記錄匯入執行者，不將其當作拍攝者；來源路徑僅供管理者追查。草稿閒置 30 天提醒本人及所屬科室管理者，不自動刪除。

系統照片儲存區由服務帳號寫入，一般同仁透過系統操作；維運例外存取另行控管。發現原圖遺失或內容改變時標記檔案異常並通知管理者，不自動替換或刪除資料庫紀錄。匯入來源區與系統儲存區分開，來源可維持原有使用方式。

本人可放棄草稿移入回收區；所屬主管或系統管理者可接管或指派有該科上傳權限者，保留原始上傳者與交接紀錄，不因帳號停用自動刪除。合法但可疑時間或位置先警示，可確認理由後提交；無法解析或超出合法經緯度範圍者列待補並保留原值。零度或服務區外位置不一律判錯，未確認可疑資訊不直接用於時間異常判定。
