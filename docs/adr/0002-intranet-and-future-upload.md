# 全內網運作，預留外網上傳邊界

2026-11-23 確認：正式系統的照片、資料庫、底圖及後續模型推論全部留在內網；照片存放指定網路芳鄰。此選擇取代運行時依賴外部底圖或雲端推論服務，部署時需準備可於內網使用的圖資、程式依賴與模型檔案。

未來有外網上傳需求，但尚未授權實作或開放外網。建議後續以獨立上傳入口與接收暫存區連接內網匯入流程；具體網路拓樸、驗證與傳輸政策待確認，不能將此需求解讀為開放後台、圖台、資料庫或網路芳鄰至外網。

外網功能邊界已確認為有帳號同仁登入、選授權目的地、上傳及查看自己的上傳進度，不開放匿名或民眾投稿，也不提供地圖、歷史照片搜尋、名冊或管理後台。第一版僅預留邊界；實際上線前確認機關網路政策與登入方式。
