# 身分、科室角色與照片權限分離

2026-11-23 確認：第一版由管理者建立或匯入帳號，不開放自行註冊；預留機關單一登入，登入身分與系統科室權限分開。支援一人多科室、各科室獨立授予角色；調職不改變歷史照片歸屬與上傳者紀錄，也不讓曾經上傳者永久保有閱覽權。停用帳號立即失去存取權，保留歷史操作紀錄；未來外網上傳仍需驗證身分。

閱覽、原圖下載及批次匯出分為不同權限。所屬科室同仁預設可下載原圖，跨科室閱覽不自動授予原圖下載，批次匯出另行授權並記錄操作者、範圍與時間。預覽圖可被使用者另存或截圖，下載權限不構成對預覽內容的防複製保證。

主管自己的更正或刪除申請由另一名具該科權限的主管或系統管理者核准；一般申請由一位有權者核准即可。系統管理者可直接處理，須填理由並留紀錄。

具該科整理權限者可替照片提出更正或刪除，記錄提出者及原上傳者；同照片同欄位已有待審更正時提示既有案件，核准前再次檢查資料是否變動。

批次匯出預設含照片、拍攝時間及位置、科室／項目／資料集、表單與人工標籤；異常、分析結果及人物資訊需另勾選且有相應權限，不匯出他人星號或伺服器實體路徑。匯出前顯示張數及內容，下載時再次檢查權限；下載包保留 7 天，到期清除不影響原圖。

科室建立停用、主管指定、跨科室授權與系統管理者指定集中由系統管理者處理，主管可提出異動申請而不自行擴權。防止停用最後一個有效系統管理者，表單與名冊管理角色不包含帳號管理權限。

未結案申請可由申請者撤回，駁回須填理由；撤回或駁回後可複製重送，產生新案連結舊案，不改寫原案。主管不直接修改申請內容後核准。照片回收使其他待審更正或搬移申請失效並通知；復原不自動執行舊案，歷史異常與分析仍保留並受回收區權限限制。
