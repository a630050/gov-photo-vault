# 以拍攝座標範圍定義附近比對

2026-11-23 確認：照片比對依基準照片的拍攝座標找附近照片，不引入業務標的編號作為同一處的判準。預設範圍為 100 公尺，僅系統管理者可調整，最低為 100 公尺；時間起訖滑桿篩選候選照片，再以並排或分隔線疊合檢視。

此設計降低人工建檔負擔，但附近不代表拍攝同一物體，亦不提供影像自動對齊。缺位置照片不出現在地圖；缺拍攝時間照片不進入時間比對；允許收存並人工補登，保留原始資訊與修正來源。距離等於半徑也納入。

清單預設跟隨地圖範圍，可切換搜尋全部範圍；附近比對固定基準照片位置，保留科室、項目與標籤篩選，另顯示比對時間範圍。同座標大量照片開啟依拍攝時間排序、分批載入的清單，支援星號與人工異常篩選。兩圖預設獨立縮放，可開啟同步縮放與移動，不代表影像已對齊。

附近比對允許跨資料集，但受閱覽權限及科室、項目、標籤篩選限制；提供預設關閉的「僅目前資料集」。近似分析仍限單資料集。一般日期篩選以臺灣日期顯示，起迄日均包含整天，進階可輸入時分秒；比對滑桿預設涵蓋附近候選的完整拍攝時間並提供日期輸入。缺時間照片在未篩時間時可見，篩時間時排除並顯示排除張數，數量仍受閱覽權限限制。
