# 近似分析由使用者啟動，限於選定資料集

2026-11-23 確認：近似分析須由使用者執行後才分析，只在該資料集內比較，不跨資料夾。即使背景工作程序執行計算，也不可自行擴大範圍或在上傳後自動發起近似分析。預設分析整個資料集，可改為僅勾選照片；啟動前顯示張數與門檻，啟動時固定成員名單，保存每次執行的獨立紀錄。

結果供具該科分析權限且能閱覽相關照片者查看，保存執行者、照片名單、時間門檻與模型版本。照片更正、回收或權限改變後舊結果標示資料已變動，開啟仍重新檢查閱覽權限；結果保存期限待確認。

拍攝時間差預設嚴格超過 24 小時，由系統管理者調整；缺時間或時區不明須標記需確認，不以檔案上傳時間替代拍攝時間。模型結果不直接認定造假，可由使用者轉為人工異常標註，交主管或系統管理者確認或排除。

近似分析屬另外授予的操作權限，預設授予所屬科室同仁；跨科室閱覽權限不自動賦予近似分析權限。

結果以近似照片組呈現，保留實際命中配對及分數，分開顯示影像近似與時間差超過門檻；不將相似關係視為具有傳遞性。可取消未完成分析，失敗可重試；部分結果標明未完成。

相似度門檻由系統管理者依模型校準及管理，一般使用者可看設定、選範圍及啟動，不自行調整門檻。每次保留模型及門檻，調整不回寫或重跑舊結果；第一版保留分析結果，清理期限待保存政策確認。

每次分析的命中配對可標記未檢閱、已檢閱無須處理、已建立異常案件，記錄檢閱者、時間及選填說明，供有權查看結果者共享。重新分析不直接沿用舊結論，但可顯示同配對歷史處理；無須處理不代表永久忽略該配對。
