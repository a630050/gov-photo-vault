# 修改衝突不覆寫，權限撤銷阻止新結果發布

2026-11-23 確認：多人修改衝突時顯示最新內容並請後操作者重新確認，不直接覆寫；審核案件只能成功結案一次。批次操作逐筆回報成功、失敗及略過，重試只處理未成功部分。

撤銷權限立即阻止帳號的新存取，執行中工作於下一安全檢查點取消，不再發布結果或提供下載；未提交上傳留受控草稿區供管理者處理，已合法提交照片不回滾。已下載檔案無法由系統收回。

應用程式不提供操作紀錄修改或刪除功能。記錄登入、授權變更、提交、更正、審核、搬移、下載匯出、分析及設定異動，修改記錄必要前後差異，不記密碼或登入憑證。紀錄查閱與匯出另設權限，第一版不自動清除；這不宣稱具資料庫或儲存管理權限者在技術上完全無法更動紀錄。

網路芳鄰中斷保留表單及可恢復上傳狀態，不宣告存檔成功，圖片讀取失敗明確顯示；底圖中斷仍提供清單與一般篩選；模型中斷保留一般搜尋與人工操作；資料庫中斷停止需驗權或寫入操作。恢復後重試不得重複建檔或建案。

上傳、瀏覽、審核優先於模型工作；模型限併發、其餘排隊。同使用者同資料集相同範圍及設定已有未完成分析時引導既有工作，不重複啟動。顯示工作狀態，不提供無依據的精確倒數。
