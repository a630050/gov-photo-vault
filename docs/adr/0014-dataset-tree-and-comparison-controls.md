# 科室下直接顯示資料集與可收折的標籤篩選

2026-11-23 使用者修正：項目本身即資料集，操作介面採「科室 → 資料集 → 照片」，不再顯示額外項目層或獨立資料集篩選下拉。科室篩選樹、各科室與標籤區可收折並記憶收折狀態；標籤以可複選膠囊按鈕顯示，提供搜尋與清除。

本機既有 Item 資料先保留作表單範本關聯，後台名稱改為表單範本，不搬動或刪除原照片；這是相容儲存方式，不是另一層業務資料夾。資料集仍有自己的唯一識別與照片集合。此決策覆蓋先前 ADR 0006 的四層操作架構；後續正式 schema 應把資料集的科室歸屬與表單範本引用分開。

同輪確認比對操作：疊合視圖可在照片畫面直接拖曳分隔線；時間起訖使用同一軌道雙把手，左側滑桿改為此次比對距離，100 至 1000 公尺。調整距離重建時間候選範圍；第二張照片退出當前條件時清除選取。此次距離不回寫管理者預設設定。
