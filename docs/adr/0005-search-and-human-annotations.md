# 語意搜尋與人工整理分離

2026-11-23 確認：模型只提供語意搜尋，不自動更動照片科室、項目或正式表單；使用者可批量新增人工標籤。人工整理與模型結果分開，避免模型更新覆蓋使用者整理。打星為個人有星／無星收藏，只需閱覽權限，可批量操作並依「我的星號」篩選。

共享標籤與人工異常標註為另外授予的操作權限，預設授予所屬科室同仁，跨科室閱覽不自動包含操作權限。此類額外註記可直接操作並留存紀錄；正式表單、時間與位置更正仍須申請。異常標註包含類型、說明、提出者及時間，供有權閱覽照片者查看；一般同仁提出，由主管或系統管理者將待確認案件確認為異常或排除。

批量標籤預設僅處理勾選照片，可明確選取全部搜尋結果；執行前顯示數量及標籤，重複標籤不重複加入，記錄批次並支援撤回該批次新增的關聯。

搜尋條件同類採任一符合，不同類採同時符合。科室表單管理為可另外授予主管或指定同仁的權限，表單以版本發布並保留歷史照片資料。人臉搜尋另設使用權限並沿用照片閱覽範圍；人員名冊功能納入第三階段，其欄位與科室邊界如下述已確認規則。

交付順序為核心照片系統、中文語意搜尋與近似分析、最後人臉搜尋及名冊。模型接口與資料結構提前預留，具體模型選型尚未定案。

驗收分三階段：核心涵蓋登入權限、上傳匯入、表單、地圖、附近兩圖比對、標籤打星、人工異常、申請審核、匯出與備份復原；第二階段驗收離線語意搜尋及資料集內近似分析與檢閱；第三階段驗收名冊、人臉搜尋及人工關聯。外網上傳另列部署階段，不阻擋內網核心驗收。

標籤庫以科室為範圍，輸入優先建議既有標籤，同仁可新增；科室指定管理者可改名、合併或停用。停用不移除歷史關聯，但停止新增使用；跨科室同名標籤各自管理。

第一版以站內通知及待辦清單處理更正、刪除、異常標註與分析完成或失敗通知。主管接收待辦，申請者接收結果，分析發起者接收分析狀態；內部郵件串接留待後續。

下一階段人員名冊以科室為範圍，由另外授權的名冊管理者維護；包含內部編號、姓名、選填備註及多張參考照片，允許同名，不以姓名作唯一識別。跨科室不自動合併，人臉命中只提供候選，人工確認後才建立正式人物與照片關聯。

一張照片可有多筆異常案件，分別記錄類型、說明及結果；異常類型由系統管理者維護，確認或排除都必須填理由，主管可附理由重開。確認異常不自動刪除，需另走刪除申請；第一版保留審核紀錄。

照片閱覽、人物姓名閱覽、人臉搜尋及名冊維護分開授權。無人物資訊權限者不顯示姓名及人物搜尋入口；具名冊維護權限者確認正式人物關聯，一般搜尋不自動寫回名冊。

批次標籤撤回僅撤回本次來源關聯，其他操作明確加入或保留者繼續存在；記錄來源並預覽移除及保留張數，遇合併等異動明確提示，不誤刪新的分類結果。

通知已讀與案件處理分開，核准、駁回及確認異常須明確操作；主管待辦按當前權限更新，歷史通知不賦予案件或照片權限。
