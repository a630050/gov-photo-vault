# 照片管理系統分階段驗收清單

基準日期：2026-11-23。配合 [技術方案](TECHNICAL-PROPOSAL.md) 及已確認 Q1–Q80。以下全部是待執行驗收項目，未勾選代表尚未驗證，不能將文件檢查當作系統測試通過。

每項保存測試版本、環境、資料集、操作者角色、步驟、預期及實際結果、必要截圖或 request_id。失敗須有可重現案例與修復後回歸證據；個資範例使用授權資料或測試資料。

## 第一階段核心系統

- [ ] **C01 帳號與科室權限**：管理者建立／匯入帳號，無自行註冊；同人兩科不同角色，調職不帶走歷史照片也不留下舊閱覽權。停用帳號的新請求立即拒絕，歷史上傳者仍可識別，最後有效管理者不可停用。
- [ ] **C02 全部讀取路徑驗權**：使用本科、跨科僅閱覽、主管、管理者與未登入者測清單、照片 ID、原圖、縮圖、群聚數字、缺時間數字、通知、申請及匯出。未授權資料不出現在內容、數量、錯誤訊息或共用快取。
- [ ] **C03 資料集與停用**：同項目名稱唯一含封存，不同項目可同名；改名不搬原圖。封存阻擋新提交、新分析、共享標籤及新異常，仍可星號及審既有案；停用項目阻擋新資料集與提交，可包含歷史查詢。
- [ ] **C04 表單版本**：測全部八類欄位、順序、必填、預設、提示及範圍。系統欄位不能刪；發布後改版不改舊照片。草稿升版需確認與補填，型別變更不合併錯誤欄位，停用仍保留歷史名稱。
- [ ] **C05 上傳與格式**：JPEG、PNG、WebP、HEIC 真實樣本含 EXIF 方向、非 ASCII 名稱；偽造副檔名及損壞圖逐檔失敗。500 張、50 MB 邊界及超限均有明確行為；測手機重選原檔重試，不重傳成功項目、不重複建檔。
- [ ] **C06 草稿與接管**：草稿只對本人／承辦與有權管理者可見；共同欄位批填、逐張修改、分批提交。本人放棄進回收，主管接管或指派保留原始上傳者；停用帳號不刪草稿，閒置 30 天通知不清除。
- [ ] **C07 時間及位置品質**：測已知時區、缺時區、缺時間、未來時間、非法座標、零度及區外座標；保留原值及確認理由，不以電腦定位或上傳時間替代。批次確認需張數與明確選取，缺拍攝時空可提交並進待補。
- [ ] **C08 原圖保存與匯入**：同資料集同 hash 預設略過、附理由可新建，跨資料集不透露命中。匯入先預覽、複製、驗證及草稿，來源不動；匯入者不當拍攝者。改分類不改 storage_key，服務帳號外一般人無 SMB 寫權。
- [ ] **C09 一般篩選**：同類 OR、異類 AND；項目自訂欄位只在單項目顯示；同識別及型別可跨版本查詢，同名不同欄位不混用。0、false、未填可區分；預設清單跟隨地圖，可查全部範圍。
- [ ] **C10 地圖群聚**：縮放與平移更新正確，點數先驗權後聚合；同座標大量照片開分頁時間清單。請求不一次傳回百萬點，切換使用者／權限版本不沿用錯誤快取，資料集張數不因群聚重複計算。
- [ ] **C11 照片檢視器**：滾輪縮放、拖曳、Esc、照片區右鍵／空白鍵與可見屬性按鈕皆有效；輸入框內空白鍵不被攔截，手機可開屬性；不同方向與尺寸顯示正確。
- [ ] **C12 附近及時間比對**：預設 100 公尺、99 公尺設定遭拒；已知測點的距離邊界包含，邊界外排除。可跨授權資料集，僅目前資料集切換有效，原地圖 bbox 不截斷附近；照片 A 不重複當候選。起迄日期包含整天，未知時間排除計數正確，滑桿拖動不縮減自身完整範圍；左右及疊合、不拉伸、獨立及同步縮放均可操作。
- [ ] **C13 星號與標籤**：星號私人、可批次及篩選；共享標籤依科室及權限管理。新增去重、停用不新增、合併保歷史；選全部搜尋結果明示 N 張並固定名單。甲撤回只撤甲來源，乙明確保留仍在；合併衝突提示影響。
- [ ] **C14 人工異常**：同照片可多案件，提出與確認角色分開；結案理由必填，主管可附理由重開。近似結果不自動認定造假，確認異常不自動刪除，案件歷史不可被後續編輯覆蓋。
- [ ] **C15 申請審核**：更正／刪除／搬移／權限異動顯示前後差異；主管本人申請由他人核准，管理者直接處理留理由。撤回、駁回理由、新案重送及舊案連結正確；審核者不能偷改提案再核准。其他本科整理者可替離職者照片申請。
- [ ] **C16 衝突與重試**：兩人同改資料集回 409 或等效衝突提示；同案同時核准只能一次成功。待審同欄位更正顯示現有案。網路重送與工作重試不重複建照片、標籤批次或審核事件；逐筆成功失敗略過可追蹤。
- [ ] **C17 移動與回收**：同項目移至未封存集，保留照片 ID、表單、標籤、星號及異常，舊分析標變動；跨科／跨項目拒絕。回收立即退出一般查詢及圖片路徑，待審更正搬移失效；復原草稿仍為草稿，不自動執行舊案。無永久清除入口及排程。
- [ ] **C18 匯出**：閱覽不等於原圖下載或批次匯出；預覽與原圖產物標示清楚。預設欄位、另授異常／分析／人物欄位、跨版本欄位字典正確；不含他人星號、實體路徑及可執行公式。產物 7 天到期，下載重驗每成員及欄位權限，失權舊包不能下載。
- [ ] **C19 通知與待辦**：申請、結果、分析、草稿提醒各送正確對象；已讀不結案。待辦依目前權限刷新，歷史通知不洩漏已失權內容，開目標再次驗權。
- [ ] **C20 管理權限分離**：主管不能指定主管或自授跨科權，表單管理與名冊管理不能管理帳號；具相應授權者可維護科室標籤。稽核讀與匯出另授，不因看到管理頁就取得全部功能。
- [ ] **C21 檔案交易邊界**：分別在接收、SMB 寫完、DB 提交前後及 Outbox 派送前後中斷；恢復後可對帳，不將未安全保存者標成功，不生成重複正式紀錄，不誤刪正式孤立原檔。
- [ ] **C22 配額與儲存異常**：資料集 1 萬張不是隱含上限；配額設定、接近提醒、併發預留及超額拒絕正確，已完成檔案保留。模擬原圖遺失、內容被改與暫時 SMB 失聯，狀態可區分且不自動替換或刪紀錄。
- [ ] **C23 中斷與降級**：底圖失聯仍能查清單，模型失聯仍能一般搜尋，broker 失聯保留 Outbox；DB 失聯不繞過驗權。恢復後逐檔／逐工作安全重試；畫面沒有把不可用顯示成空結果或成功。
- [ ] **C24 撤權中的工作**：分析、匯出、上傳中途停用或撤 scope，新請求立即拒絕，下一安全檢查點取消工作且不發布產物；已合法提交照片保留，受控草稿可交接。無長效直接下載網址繞過撤權。
- [ ] **C25 稽核與離線運行**：必要操作、前後差異及 request_id 可追溯，沒有密碼／token；應用程式不可改刪紀錄。切斷外網後登入、字型、地圖、照片與表單正常，瀏覽器及伺服器沒有必要 CDN／外部 API 依賴。

## 容量效能與復原

- [ ] **N01 環境紀錄**：記錄 CPU、RAM、磁碟、SMB 實測吞吐、套件版本、資料分布、圖片大小與測試負載；100 萬筆照片中繼資料、單集 1 萬張含空間密集與同點情境，真實圖片樣本測解碼及串流。
- [ ] **N02 互動效能**：100 人混合使用且其中 10 人上傳時，一般地圖與欄位篩選 p95 ≤3 秒；報告冷暖快取、各端點分位數與錯誤率，不以平均值取代 p95。此標準不包含模型完成時間或整批圖片傳輸。
- [ ] **N03 上傳容量**：測 10 人同時提交批次、大小分布及極端 500×50 MB 受控案例，記憶體不隨整批線性占滿；暫存配額不足可預期拒絕且不丟已完成檔案。
- [ ] **N04 工作隔離**：背景索引或分析滿載時，上傳瀏覽審核仍達已定互動目標；併發限制、工作取消、心跳失聯、重新派送與重複工作檢查有效。
- [ ] **N05 備份完整性**：DB、原圖 manifest、必要設定及權限可還原至一致點，備份獨立故障域、保留 30 天，最近可復原點不超過 24 小時；備份失敗有可取得的維運告警。
- [ ] **N06 實際復原**：在隔離環境計時復原，核心服務於 1 個工作日內恢復；測照片 hash、權限、回收狀態及申請歷史一致。缺最新撤權事件時不直接開放舊權限資料，待對帳；縮圖與索引後續重建。
- [ ] **N07 升版與回復**：DB 遷移前備份，程式及 schema 相容路徑明確；失敗可回復版本或還原，不能只替換程式而忽略 DB。機關設備若未達目標，留下容量實測及調整方案，不將規格寫成已達成。

## 第二階段離線模型

- [ ] **M01 語意索引生命週期**：正式提交才自動索引，草稿不進；顯示索引覆蓋不足。回收／撤權立即影響結果，即使實體向量尚未刪；不同版本維度不混用。
- [ ] **M02 中文搜尋品質**：使用事先固定測試集，涵蓋繁體機關詞、同義詞、夜間模糊、無相關照片與授權子集；回報 Precision@K、Recall@K、查詢延遲及無相關結果行為。正式門檻需在啟用前由業務方確認，不能只展示少數成功例。
- [ ] **M03 近似範圍**：未按執行不分析；單資料集及勾選範圍正確，無 GPS 亦可比近似，不跨集查。名單／revision/hash 固定，新照片不自動加入；同人相同未完成工作不重複排程。
- [ ] **M04 近似品質與時間**：測完全相同、重存壓縮、裁切、旋轉及固定場景但不同照片，量測配對 precision/recall。24 小時整不命中時間異常、超過才命中；缺／推定未確認／可疑時間不直接判定，不能宣稱近似等於造假。
- [ ] **M05 配對檢閱**：群組保留實際邊，A-B、B-C 不偽造 A-C；無須處理及轉異常記錄正確，重跑不自動沿用舊結論。照片更正、搬移、回收時舊結果標變動，權限仍即時套用。
- [ ] **M06 工作復原**：排隊、執行、取消、失敗、部分結果可辨；殺掉 worker 後可安全重試，不重複 pair。分頁不漏報，任何截斷或候選近似性在結果及評估中明示。
- [ ] **M07 模型升版**：權重、前處理、tokenizer、門檻及授權可追溯；影子索引建好並測試再切換，可回復舊版。全程斷外網不觸發下載，不使用未核准模型權重。
- [ ] **M08 一萬張分析**：測單資料集一萬張、記錄耗時峰值記憶體與結果量；不逐對反覆解碼原圖。候選召回若近似，須提供漏召回評估；模型負載不能破壞核心 N02 目標。

## 第三階段人物功能

- [ ] **P01 名冊**：科室隔離、UUID 唯一、同名不同人、多參考照片、跨科不自動合併；參考照片及姓名只能由適當授權存取。
- [ ] **P02 分開授權**：照片可看但姓名不可看、可見姓名但無搜尋、可搜尋但無維護等組合皆測；一般同仁無法藉候選分數、快取或匯出取得未授權人物資訊。
- [ ] **P03 人工確認**：一圖多臉，候選不自動建關聯；只有名冊維護者確認，修正保留歷史。無法可靠偵測或品質不足不強制匹配某人。
- [ ] **P04 品質與授權**：以授權代表樣本評估錯誤匹配、漏匹配及低品質處理，門檻在正式啟用前確認；偵測、對齊與辨識各模型權重均有可追溯使用條件。
- [ ] **P05 生命週期**：照片回收／撤權立即退出可見候選；人物參考資料、觀測向量與人工關聯均遵守相同範圍。正式刪除政策尚未完成時不新增永久清除捷徑。

## 外網上傳階段

- [ ] **E01 邊界**：只有已驗證同仁可用，匿名與民眾註冊不可用；外網無地圖、歷史照片搜尋、名冊、後台、DB 或 SMB 存取路徑。
- [ ] **E02 接收匯入**：DMZ 暫存、格式驗證及內網拉取依核准網路方向運作；不把 SMB 憑證交外網前端，不由上傳者提供任意內網路徑。
- [ ] **E03 授權與進度**：只能選有權目的地及看本人上傳進度；上傳後內網匯入前再次驗權。封存、撤權、超額、重試及重複拉取不產生越權或重複資料。
- [ ] **E04 維運與復原**：網路政策、憑證、登入及暫存處置已確認；入口關閉不影響內網核心，失聯可恢復且不把僅存 DMZ 的檔案宣告內網正式提交完成。
